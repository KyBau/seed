# Changelog
## 0.3.1 (2026-10-15)
- The command is `seed <post or idea>` (replaces the old tagline). Redesigned landing page.

## 0.3.0 (2026-10-15)
- Free-text seeds: entity and phrase extraction, query variants, anchor-based relevance filter, per-domain cap, low-confidence fallback.
- Skills use seed_hunt for one-call hunting. Homepage is seedlabs.onrender.com.

## 0.2.0 (2026-10-15)
- New seed_hunt: one-call autonomous research from a post URL or idea (Bing RSS, DuckDuckGo, Hacker News, Reddit, optional X API), with request budget and per-host rate limit.

## 0.1.1 (2026-10-15)
- Hype flags: case-insensitive, comma thousands, into/to/->, Nx multipliers, wins+losses vs trades, hit-rate check.
- Better keywords and queries: bigger stopword list, no min_faves, distinctive terms.

## 0.1.0 (2026-10-15)
- First version: 5 skills (grow, distill, sprout, feed, watch) and a dependency-free MCP server with 7 tools.
