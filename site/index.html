How it works

From one seed to a full field of knowledge.

You plant it once. Seed follows the leads, keeps only the relevant finds, and checks what doesn't add up.

01

Seedseed …

Start from an X post or a plain-English idea. It pulls out the names, @handles, $tickers and key phrases that matter.

02

Hunt

It follows quotes, replies and linked articles, then searches the web for more. Keyless sources come first, every call fits a request budget, and junk gets filtered out.

03

Distill

It groups duplicate ideas, keeps a source link on every claim, and flags the hype: impossible returns, math that doesn't add up, paid pitches.

04

Sprout

It drafts a bot blueprint with multiple-choice build questions based on what it found. Then it keeps watching and sends a daily digest.
