Seed

Plant one post. Grow a knowledge base. Sprout a bot.

You find a great post about a strategy, and five minutes later you find another one with a different take. Seed starts from a single X post, finds the related posts, replies, and articles on its own, and merges them into one cited playbook. When a topic is ready, it drafts an agent for you and asks the build questions up front.

GROWFollows quotes, replies, and linked articles two levels deep, then searches X and the web for more.
DISTILLGroups duplicate ideas, cites every source, and flags hype like 88 wins in 97 trades with 37 losses.
SPROUTDrafts a bot blueprint with multiple-choice questions drawn from what it learned.
FEEDSends new ideas to the agents you already run instead of starting duplicates.
WATCHSends a daily digest of what's new on each topic. If nothing changed, it says so.

Safe by default

  • Read-only. It never posts, likes, follows, DMs, buys, or signs up for anything.
  • No API key needed to read posts. Broad search uses your host's X access.
  • Every claim gets a source and a label: CONFIRMED, REPORTED, or CLAIM.
  • Your knowledge base stays on your machine as plain JSON.

Install

In Grok, Grok Bot, or Cursor, open the plugin marketplace and add Seed. Then tell your agent: seed this https://x.com/…/status/…
